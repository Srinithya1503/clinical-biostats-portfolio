# Clinical Trial Operational Assessment Workbook

---
## Overview

Portfolio project demonstrating protocol interpretation and clinical
trial operations planning using an educational mock protocol.

3. Study Design Review
4. Site Feasibility Assessment
5.  Study Start-Up Activities - Include - Ethics, Contracts, Budget, Vendor onboarding, System access, Training, SIV

7.  Visit Assessment Matrix Professional table.
Include - Visit, Purpose, Assessments, Laboratory, Investigational Product, Source Documents, Responsible Staff
8. Roles and Responsibilities - Create a RACI matrix.
9.  Pharmacy Operations
10. Laboratory Operations
11. Vendor Management
12. Data Management - Explain - Source, eCRF, EDC, Queries Monitoring, Database Lock
13. Risk Register - Create a realistic operational risk register.
14. Monitoring Activities
15. Study Close-Out
16. Lessons Learned
